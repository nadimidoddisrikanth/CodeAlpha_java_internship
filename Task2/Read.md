#  Stock Trading Platform

##  Project Description

The Stock Trading Platform is a Java-based console application that simulates a basic stock trading environment.

The application allows users to view available stocks, buy and sell stocks using virtual money, manage their investment portfolio, view transaction history, and track portfolio performance.

This project was developed as part of the **CodeAlpha Java Programming Internship**.

> **Note:** This is an educational stock market simulation. It does not perform real stock-market transactions or use real money.


## 🎯 Objectives

The main objectives of this project are:

- Simulate a basic stock trading environment.
- Display available market data.
- Allow users to buy stocks.
- Allow users to sell stocks.
- Maintain a virtual investment portfolio.
- Track available cash balance.
- Calculate current portfolio value.
- Calculate profit or loss.
- Maintain transaction history.
- Demonstrate Object-Oriented Programming concepts in Java.
