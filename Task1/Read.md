# Student Grade Calculator

# Description

A Java-based console application that allows users to enter
student names and scores and generates a summary report.

# Features

- Add student names and scores
- Calculate average score
- Find highest score
- Find lowest score
- Automatically assign grades
- Display a summary report

# Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Scanner
- Conditional Statements
- Loops

# How to Run

Compile the program:

# terminal or bash
javac StudentGradeManager.java
